unzipgit

unzip archives into a GitHub repository

Advanced
100% client-side GitHub API

readme

UnzipGit extracts a .zip archive straight into a GitHub repository. Everything runs in your browser — the archive and your token are sent only to api.github.com.

Quick start

  1. Create a personal access token with the repo scope. For fine-grained tokens use Contents: read & write.
  2. Enter the repository owner and name, e.g. octocat/hello-world.
  3. Optionally add a folder after the repo name, e.g. hello-world/site, to extract into it.
  4. Pick a .zip from your device, or give the path of an archive already in the repo.
  5. Press Unzip into GitHub.

Good to know

  • The token is never stored; it only lives in memory for this page.
  • Files are committed in one atomic commit when possible. If that is blocked, UnzipGit falls back to uploading file by file.
  • Existing files with the same path are overwritten, everything else is left untouched.
  • The default branch is used unless you choose another one under “Advanced”.
  • Up to 1500 files per archive. Very large archives can hit GitHub API rate limits.

UnzipGit آرشیو .zip را مستقیماً داخل یک مخزن گیت‌هاب از حالت فشرده خارج می‌کند. همه‌چیز در مرورگر شما اجرا می‌شود — آرشیو و توکن فقط به api.github.com فرستاده می‌شوند.

شروع سریع

  1. یک توکن دسترسی شخصی با دسترسی repo بسازید. برای توکن‌های Fine-grained از Contents: read & write استفاده کنید.
  2. مالک و نام مخزن را وارد کنید، مثلاً octocat/hello-world.
  3. اختیاری: بعد از نام مخزن یک پوشه اضافه کنید، مثل hello-world/site، تا فایل‌ها داخل آن باز شوند.
  4. یک فایل .zip از دستگاه انتخاب کنید یا مسیر آرشیوی که از قبل در مخزن است را بنویسید.
  5. روی از حالت فشرده خارج کن بزنید.

نکته‌ها

  • توکن ذخیره نمی‌شود و فقط در حافظهٔ همین صفحه می‌ماند.
  • در صورت امکان همهٔ فایل‌ها در یک کامیت اتمیک ثبت می‌شوند. اگر این روش مسدود باشد، آپلود فایل‌به‌فایل انجام می‌شود.
  • فایل‌های هم‌نام بازنویسی می‌شوند و بقیهٔ فایل‌ها دست‌نخورده می‌مانند.
  • به‌طور پیش‌فرض شاخهٔ اصلی مخزن استفاده می‌شود؛ از بخش «پیشرفته» می‌توانید شاخهٔ دیگری بدهید.
  • حداکثر ۱۵۰۰ فایل در هر آرشیو. آرشیوهای بزرگ ممکن است به محدودیت نرخ API گیت‌هاب بخورند.
